# Code signing policy

Free code signing provided by [SignPath.io](https://signpath.io/), certificate by [SignPath Foundation](https://signpath.org/).

## Overview

Official Windows release artifacts for EverythingToolbar are built automatically from source code in the [srwi/EverythingToolbar](https://github.com/srwi/EverythingToolbar) repository using GitHub Actions and signed via SignPath.io.

Because the code signing certificate is issued to the SignPath Foundation, the publisher on signed executables and Windows SmartScreen / UAC dialogs is displayed as **SignPath Foundation**.

## Roles and Responsibilities

- **Authors and Committers:** [@srwi](https://github.com/srwi)
- **Reviewers:** [@srwi](https://github.com/srwi)
- **Approvers:** [@srwi](https://github.com/srwi)

Every signing request submitted to SignPath is reviewed and approved by an authorized Approver prior to release artifact distribution.

## Privacy Policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.
